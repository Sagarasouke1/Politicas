# 📌 CHANGELOG

Todos los cambios relevantes sobre la política de acceso, seguridad y auditoría de infraestructura TI serán documentados en este archivo.

Formato basado en buenas prácticas de versionado documental.

---

## [1.0.0] - 2026-05-05

### Agregado
- Política de acceso y seguridad a infraestructura TI.
- Procedimiento de acceso no evadible.
- Matriz de accesos defensiva.
- Estándar técnico obligatorio para Linux SCP y Windows ANALÍTICA.
- Lineamientos de auditoría de accesos.
- Restricción de accesos por jerarquía.
- Control de acceso por VPN.
- Modelo de acceso temporal y auditado.
- Cláusula anti-bypass.
- Control de continuidad operativa bajo evidencia.

### Seguridad
- Se establece principio de mínimo privilegio.
- Se prohíben accesos compartidos.
- Se restringen privilegios root/administrador.
- Se requiere trazabilidad completa de accesos.

### Notas
- Esta versión establece la base documental.
- La implementación técnica deberá aplicarse en servidores, VPN y mecanismos de auditoría.
